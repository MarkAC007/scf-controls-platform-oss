Paste the setup token

The launcher printed a token in your terminal. It is stored in a file next to your secrets, never in a link.

Where should the platform store its data?

Validation is not applicable to the bundled database: the stack initialises PostgreSQL with the generated password the first time it starts.

The string is parsed into parts and rebuilt. Extra libpq parameters are refused.

    How will people sign in?

    The secret is written to a file, never to .env. Leave it blank for a public client.

    This is Keycloak's own infrastructure account. Its password is generated and never shown; you will not use it to sign in to the platform.

    Keycloak creates this user with a one-time temporary password printed to the idp-init container log. You set your own password at first sign-in.

    Review

    Ten credential files will be created in your secrets directory with mode 0600. None of them is displayed here or anywhere else. Existing files are never overwritten.
